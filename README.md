# ตลาดขนมหวาน (Sweet Market)

เกมจับคู่ขนมหวานบนเว็บ เล่นได้ทั้งมือถือและคอมพิวเตอร์ ปีนต้นไม้ผ่านด่านต่างๆ ที่เปลี่ยนธีมตามระดับความยาก เก็บเหรียญ ใช้ไอเทมช่วย ทำภารกิจ และสะสมไพ่ทาโรต์

ตอนนี้เป็นเวอร์ชันออฟไลน์ ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร

## ฟีเจอร์

- แผนที่เป็นต้นไม้ มีกระรอกบอกตำแหน่งด่านปัจจุบัน
- กระดานหลายรูปทรง มีช่องน้ำแข็งให้ทุบ
- หัวใจ (ฟื้นตามเวลา) และเหรียญ
- ไอเทมช่วย: ค้อน ครก พัด โคมวิเศษ สับขนม และคำใบ้
- ภารกิจที่สุ่มรางวัลให้
- ร้านค้า และสมุดไพ่ทาโรต์
- เพลงประกอบและเสียงเอฟเฟกต์ (เปิดปิดได้)
- บันทึกความคืบหน้าอัตโนมัติในเครื่อง

## รันในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

ถ้าต้องการรันผ่านเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

## โครงสร้างโปรเจกต์

```
.
├── index.html   # เกมทั้งหมด (HTML + CSS + JavaScript)
└── README.md
```

ไม่มีขั้นตอน build และไม่มี dependency ภายนอก ยกเว้นฟอนต์ที่โหลดจาก Google Fonts

## นำขึ้น Render (Static Site)

1. push โค้ดขึ้น GitHub (ไฟล์เกมต้องชื่อ `index.html`)
2. ที่ Render เลือก **New → Static Site** แล้วเชื่อมกับ repo
3. ตั้งค่า
   - **Build Command:** เว้นว่าง
   - **Publish Directory:** `.`
4. กด Deploy ทุกครั้งที่ push เข้า `main` Render จะอัปเดตให้อัตโนมัติ

ข้อควรรู้:

- ความคืบหน้าของผู้เล่นเก็บใน `localStorage` (คีย์ `sweet-market-v2`) ซึ่งผูกกับโดเมน ถ้าเปลี่ยนโดเมน ข้อมูลเซฟจะไม่ตามไป ควรตั้งโดเมนถาวรก่อนเปิดให้คนเล่น
- ถ้าเน็ตของผู้เล่นบล็อก Google Fonts เกมจะใช้ฟอนต์สำรอง ถ้าต้องการให้ชัวร์ ให้เก็บไฟล์ฟอนต์ Mitr และ IBM Plex Sans Thai ไว้ใน repo

## แผนพัฒนา: เล่นออนไลน์และระบบเพื่อน

เป้าหมายคือให้เห็นว่าเพื่อนเล่นถึงด่านไหน

- [ ] ระบบบัญชีผู้เล่น (ล็อกอินด้วย LINE, Google หรืออีเมล)
- [ ] ย้ายข้อมูลบันทึกจาก `localStorage` ไปฐานข้อมูล โดยยังเก็บในเครื่องเป็นสำรองตอนออฟไลน์
- [ ] ย้ายหัวใจ เหรียญ และรางวัลภารกิจไปให้เซิร์ฟเวอร์เป็นคนตัดสิน (ตอนนี้ใช้เวลาเครื่องและสุ่มในเครื่อง จึงแก้ได้ง่าย)
- [ ] ตรวจผลจบด่านฝั่งเซิร์ฟเวอร์ก่อนปลดล็อกด่านหรือให้ดาว
- [ ] เพิ่มเพื่อนด้วยโค้ดเชิญหรือลิงก์
- [ ] แสดงอวาตาร์เพื่อนบนแผนที่ที่โหนดด่านที่เพื่อนไปถึง
- [ ] หน้ารายชื่อเพื่อนและจัดอันดับ
- [ ] ส่งหัวใจให้เพื่อน

แนวทางหลังบ้านที่แนะนำสำหรับเริ่มต้น: Supabase หรือ Firebase (มีล็อกอิน ฐานข้อมูล และอัปเดตสดในตัว) หรือเขียนเซิร์ฟเวอร์เองด้วย Node.js และ Postgres บน Render

## ส่วนประกอบในโค้ด

ทั้งหมดอยู่ใน `index.html` แบ่งคร่าวๆ ดังนี้

- ส่วนบน: ตัวแปรสีและสไตล์ (ธีมสีเปลี่ยนตามระดับของด่านผ่านตัวแปร CSS ชุดสไตล์สกินสมัยใหม่อยู่ท้ายบล็อก `<style>`)
- ส่วนกลาง: โครงหน้าจอ แผนที่ หน้าเกม และหน้าต่างต่างๆ
- ส่วน `<script>`: ข้อมูลธีม ระบบบันทึก (`load()` / `persist()`) เสียง ภารกิจ ตรรกะกระดาน การวาดด้วย canvas และแผนที่ SVG
